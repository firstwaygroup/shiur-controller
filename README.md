# Shiur Controller

One tap starts the nightly shiur: the wall screen, the Zoom meeting and OBS, controlled from one simple app on the laptop.

- **ME** — Zoom sees you; the wall shows the title.
- **SHOW** — the wall and Zoom see a picture or video from tonight's list.
- **SCREEN** — the wall and Zoom see your laptop screen, live.

## Install (first time)

1. Download `shiur-app.zip` from the latest [release](../../releases/latest).
2. Extract it and double-click **Install Shiur**.
3. Tap the **Shiur** icon on the desktop. Setup opens the first time.

After that, the app updates itself from the latest release whenever it starts.

Needs Windows 11, [Node.js](https://nodejs.org) (LTS) and [OBS Studio](https://obsproject.com).

See `CLAUDE.md` for how it works, testing and releasing.
